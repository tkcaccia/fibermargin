# FiberMargin manuscript release, 2026-08-27

This directory contains the JMLR manuscript and supplementary material in PDF
and DOCX formats. Both formats were rendered and visually inspected page by page.
The manuscript description matches the public `fibermargin` 0.1.0 implementation:
specimens are independent, effective dimensionality is determined per specimen,
constant axes are removed, genuine 3D coordinates are retained, and `workers` is
one shared deterministic native CPU budget.
